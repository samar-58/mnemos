# Security policy

Computer History handles potentially sensitive local context. Please do not disclose suspected security or privacy vulnerabilities in a public issue.

Until a dedicated security contact is published, open a GitHub Security Advisory in this repository with:

- the affected component and version or commit;
- steps to reproduce;
- the potential privacy or security impact; and
- any suggested mitigation.

Do not include real captured user content, credentials, or unredacted database files in a report. Use synthetic examples instead.

The project is currently an early prototype and has no supported production release. Security fixes will be prioritized, but no response-time guarantee is available yet.
